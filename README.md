# 🐾 Mascotas y Vacunas

Proyecto para gestionar mascotas, vacunas y vacunaciones.

## Descripción

Este proyecto forma parte del proyecto intermodular de DAM.

La aplicación permitirá registrar usuarios y gestionar sus mascotas,
vacunas y vacunaciones.

El proyecto está compuesto por una aplicación Android y una API REST.

## Tecnologías

### Android
- Kotlin
- Jetpack Compose

### API
- Java 17
- Spring Boot
- Spring Security
- JWT
- MariaDB
