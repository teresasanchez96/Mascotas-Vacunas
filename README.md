# 🐾 Mascotas y Vacunas

Aplicación Android para gestionar mascotas, vacunas y vacunaciones, desarrollada como parte del proyecto intermodular del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 📋 Descripción

**Mascotas y Vacunas** es una aplicación que permite a los usuarios registrarse e iniciar sesión para gestionar sus mascotas y consultar la información relacionada con sus vacunas y vacunaciones.

El proyecto está compuesto por dos partes principales:

- **Aplicación Android:** interfaz desde la que los usuarios interactúan con la aplicación.
- **API REST:** servicio encargado de gestionar la comunicación entre la aplicación y la base de datos.

## ✨ Funcionalidades

- Registro de usuarios e inicio de sesión.
- Autenticación mediante JWT.
- Gestión de mascotas asociadas a cada usuario.
- Consulta, creación y edición de mascotas.
- Gestión de fotografías de las mascotas.
- Comunicación entre la aplicación Android y la API REST.

*El proyecto continúa en desarrollo, por lo que algunas funcionalidades pueden estar pendientes de implementación.*

## 🛠️ Tecnologías utilizadas

### Android

- Kotlin
- Jetpack Compose
- Material 3
- Gradle

### API REST

- Java 17
- Spring Boot
- Spring Security
- JWT
- MariaDB
